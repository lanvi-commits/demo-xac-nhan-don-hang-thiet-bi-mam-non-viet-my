# Demo trang Xác nhận đặt hàng — Thiết bị mầm non Việt Mỹ

Mockup trang `/checkout/order-received/` của site Việt Mỹ do THC Media dựng (website-demo-02.thcmedia.vn),
sửa theo 6 dòng review "Xác nhận đặt hàng" trong tab Review tổng thể website (dòng 232–237).

- Công tắc **Hiện tại ↔ Đề xuất**, 3 tình huống: đơn tiền mặt, đơn chuyển khoản, không tìm thấy đơn; khung desktop / mobile 390.
- Mã đơn, người đặt, địa chỉ là dữ liệu mẫu. Sản phẩm và giá là sản phẩm thật trên site (23/10/2026).
- Ghi chú cho DEV (PHP, template, CSS, JS) nằm ngay trong trang.

`index.html` do `build.py` trong thư mục dựng ghi ra — đừng sửa tay.
